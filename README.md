# Victor FG Williams

I build and deploy evaluation-gated AI agents, developer tools, and local-first speech systems across **Python**, **Swift**, and **TypeScript**.

### Selected Projects

- **[RockLang](https://github.com/FG-Baba/RockLang)**: Local-first macOS (`SwiftUI`) and `Python` voice tutor and speech evaluation harness for Igbo, Korean, and French. Includes LoRA speech fine-tuning (`NaijaVox-2.0` improved from `44.6%` to `39.6%` WER on held-out `FLEURS` validation clips), dual-recognizer uncertainty spans, `NLLB-200` local translation, and `155` Python plus `32` Swift offline tests.
- **[tinker-sft-lab](https://github.com/FG-Baba/tinker-sft-lab)**: Cost-guarded supervised fine-tuning CLI for Thinking Machines' Tinker API. Enforces offline JSONL schema validation, a 10 MB dataset cap, step and sample ceilings, and a two-key `--execute` gate before any billed GPU call can start.
- **[north-america-rabbit-hole](https://github.com/FG-Baba/north-america-rabbit-hole)**: Interactive three-act `React 19`, `TypeScript`, `HTML5 Canvas`, and `Cloudflare Workers` visual story on how plate tectonics, watersheds, Indigenous Nations, and treaties shaped North America, with Worker SSR verification tests.
- **[pe-matcher](https://github.com/FG-Baba/pe-matcher)**: Structured company profile extractor and private-equity thesis matcher using `Claude` and `Python` with SSRF-hardened web fetching and explicit field-level confidence scoring.
